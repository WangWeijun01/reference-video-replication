# reference-video-replication · 竖屏短视频复刻 / 混剪 skill

给 Claude Code 用的 skill。核心是**爆款复刻**：你给一条参考视频（比如你看中的爆款），AI 代理把它按句拆开（台词、节奏、每段作用、镜头内容），照这个结构做一条新的 9:16 竖屏短视频，交付前自动做一轮审计：没有源字幕残留、没有半截 logo、镜头不重复、音轨一致。

**混剪是它出画面的方式**：新片子的画面用多条素材剪辑拼接，加自制动效、字幕和音轨。没有参考视频时，也可以只用这套方式做自由混剪或口播拼接。

它不是一个一键出片的程序。它是写给 AI 代理的一套工作方法和配套脚本：代理照着 `SKILL.md` 的流程去找素材、看片、写剪辑计划、调用脚本渲染和审计。

**它不会替你挑爆款**：参考视频由你提供；它负责把这条视频拆开并复刻出来。

| 你给什么 | 它怎么做 |
|---|---|
| 自家/客户账号的参考视频 | 台词和节奏贴近原句保留，画面换成新素材 |
| 别家账号（竞品、博主）的参考视频 | 只学结构和节奏，台词重写、换新配音，不搬原台词和原声 |
| 没有参考视频，只有素材 | 自由混剪，或用主播原声做口播拼接 |

## 它能做什么

### 输入

你给代理的东西，任选其一或组合：

| 输入 | 例子 |
|---|---|
| 参考视频 | 本地 mp4，或一条抖音作品链接 |
| 素材来源 | 品牌的抖音官方号、你本地的素材文件夹 |
| 目标 | 给哪个品牌/产品做、拿来干嘛（谈客户样片 / 发布）、大概多长 |
| 可选 | 火山语音账号（商用配音）、指定音乐、指定字幕样式 |

### 过程

1. **找素材、下载素材**
   - 代理用浏览器（Claude in Chrome）打开抖音账号主页或作品页，读出作品列表，按剪辑需要挑镜头，再把选中的作品下载到本地。
   - 抖音网页版看账号作品列表要登录，**登录需要你本人扫码**，代理不输入账号密码，不绕验证码。
   - 下载方式：作品页正常播放时页面已经加载的视频文件；或你指定的解析下载网站。
   - 通用空镜可从 Pexels（免费商用）补，背景音乐可用 Mixkit 免版权音乐。
2. **看片、拆解**
   - 每秒一帧的联系表看全片，`ffmpeg` 量镜头切点。
   - `faster-whisper` 本地转写口播，按句整理“原句 / 证据 / 镜头公式 / 待确认项”。
3. **选做法并剪辑**
   - **贴近原句复刻**：自家账号的片子，保留台词和节奏，替换画面。
   - **保留结构、重写台词**：别家账号的片子，只学结构和节奏，台词重写，用 AI 配音（edge-tts 只适合样片；商用可接火山 seed-tts-2.0）。
   - **全屏混剪**：多条素材剪成一条，配音乐和屏幕字，可加自制动效图形（关键词、品牌尾板、示意卡片等）。
   - **口播拼接**：用主播原声挑句拼接，主播出镜画面和声音取自同一时刻（口型对得上），中间穿插空镜。
4. **渲染**：1080×1920 竖屏，字幕样式 5 种（底栏、黄底、大字描边、通栏、答题卡），低清素材轻度增强。
5. **交付审计**（必经）：
   - 源素材登记哈希；裁切不能碰源字幕区、不能把品牌标志切成半截。
   - 同一源时间不能重复用；同一组镜头离开后不能再回来（标了 `a_roll` 的口播主播镜头只要源时间往前走就可以）。
   - 成片帧数、音轨解码一致、全文件解码。
   - 代理看导出后每段起/中/尾帧写视觉复审，复审绑定计划和成片哈希。
   - 只有 `audit.json` 里 `delivery_allowed=true` 才交付。

### 输出

- 成片 MP4（1080×1920）
- 剪辑计划 `plan.json`（每段素材来源、源时间、裁切、字幕）
- `verification.json`（渲染校验）、`audit.json`（审计结论）、视觉复审记录
- 素材来源清单（作品 ID、源时间区间）和待确认项（授权、未核实的说法、画质限制）

## 它不能做什么

- **不会自动找“爆款”**：不读播放量、点赞、转化数据。选素材看的是画面能不能接住台词，账号名、标题、互动数不能代替看片。要判断爆款，得你另外提供数据。
- **不能绕过平台限制**：登录、验证码由你本人处理；不调隐藏接口。
- **不解决版权授权**：素材“能下载”不等于能二次发布，授权要单独确认。免费 AI 配音（edge-tts）商用授权不明确，只用于样片。
- **听不了声音**：音色、音乐好不好听要人耳判断；成片转写回来只能核对字句。
- **不做 AI 超分**：低清素材只做轻度去噪锐化，救不回码率太低的源。
- **只做竖屏 9:16**。
- **审计不是逐帧人工审片**：机器检查 + 代理抽帧复审，不证明产品事实或营销效果。

## 安装

```bash
git clone https://github.com/WangWeijun01/reference-video-replication ~/.claude/skills/reference-video-replication
```

然后在 Claude Code 里说“按这条参考视频复刻一条”或“用某品牌抖音号的素材做个混剪”，代理会加载这个 skill。

### 依赖

| 依赖 | 用途 |
|---|---|
| Python 3.11+、Pillow、NumPy | 渲染、审计 |
| ffmpeg / ffprobe | 剪切、编码、量切点 |
| faster-whisper | 本地转写（首次运行会下载模型） |
| edge-tts（可选） | 样片配音 |
| 火山语音 seed-tts-2.0（可选） | 商用配音；凭证只放环境变量 `VOLC_APP_ID`、`VOLC_TOKEN` |
| 中文字体 | 默认 Windows 微软雅黑，其他系统在计划里用 `font`/`font_bold` 指定 |
| Claude in Chrome（可选） | 浏览器里找抖音素材 |

## 目录

```
SKILL.md                         工作流程与规则（代理读这个）
references/
  fullscreen-mix.md              全屏混剪计划 JSON 格式、字幕样式、配音音色
  delivery-audit.md              交付审计流程与登记格式
scripts/
  render_fullscreen_mix.py       全屏混剪渲染（实拍 + 自制动效 + 字幕 + 音轨）
  render_picture_replacement.py  替换画面、保留原音轨的粗剪
  audit_video_delivery.py        交付审计（prepare / final 两阶段）
  tts_lines.py                   按句 AI 配音并排出时间线
  retime_plan.py                 换配音后按新时间线重排字幕和切点
  transcribe_local.py            本地转写（faster-whisper）
  scan_media.py                  媒体参数、哈希、按秒预览图
  validate_material_map.py       素材匹配清单校验
```
